Variables de flujo estandarizadas

Nomenclatura FLUXNET 2015 mapeada a variables núcleo del pipeline

NEE
Net Ecosystem Exchange — Intercambio neto de CO₂
~88% valid daily records
GPP
Gross Primary Production — Producción primaria bruta
~85% valid daily records
LE
Latent Heat Flux — Flujo de calor latente (evapotranspiración)
~82% valid daily records
H
Sensible Heat Flux — Flujo de calor sensible
~83% valid daily records
TA
Air Temperature — Temperatura del aire
~95% valid daily records
SW_IN
Incoming Shortwave Radiation — Radiación solar incidente
~93% valid daily records

Prioridad de fuentes de datos

  2. Librerías Python documentadas — pandas, numpy, folium
  3. Herramientas programáticas — sin scraping HTML

El notebook no intenta eludir licencias, autenticación o restricciones de acceso. Todas las limitaciones quedan documentadas en download_log.csv.

Metodología del Utility Score

Score sintético 0–1 para comparación entre estaciones

📅
Cobertura temporal
(años de datos) / 10 · máximo 1.0
📈
Completitud
Fracción de registros diarios válidos (no-NaN)
🔬
Variables disponibles
N variables núcleo presentes / 6
✔️
Calidad QC
Fracción de días con ≥50% registros 30-min de buena calidad
